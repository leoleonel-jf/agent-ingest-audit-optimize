# Support

Use the project's [GitHub issue tracker](https://github.com/leoleonel-jf/agent-ingest-audit-optimize/issues) for:

- installation and packaging problems;
- reproducible behavior defects;
- portability reports;
- documentation corrections;
- feature proposals.

Before opening an issue, include the plugin version, host/client, operating system, relevant prompt, expected behavior, actual behavior, and the smallest safe reproduction. Remove credentials, personal data, proprietary content, and confidential logs.

For sensitive security reports, follow [SECURITY.md](SECURITY.md) instead of posting exploit details publicly.

Support is provided on a best-effort basis. No response-time or service-level commitment is offered.
