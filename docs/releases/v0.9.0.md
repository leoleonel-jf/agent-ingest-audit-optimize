# Agent Ingest, Audit & Optimize v0.9.0

Packaging brought up to the plugin formats as they stand today. What an audit does is unchanged.

## Changes

`docs/specs/2026-11-19-plugin-formats.md`.

- **`/dashboard` now works outside this repository.** It invoked its script by a path relative to
  this repository, so from any other project it failed. It is now a plugin skill that finds the
  script through `${CLAUDE_PLUGIN_ROOT}`. You still type `/agent-ingest-audit-optimize:dashboard`,
  and the model cannot start it on its own;
- **A root `plugin.json`**, the manifest the Agent Plugins 1.0.0 specification requires. The Claude
  Code and Codex manifests stay; all three are held to one name and one version;
- **The Codex listing fits the directory's limits**: a 27-character `shortDescription` and a
  `supportURL`;
- `SKILL.md` says where `dashboard.py` is.

Validated on the extracted archive, outside any checkout, with Claude Code 2.1.326 and codex-cli
0.146.0.
