# Agent Ingest, Audit & Optimize v0.1.0

Initial public release of the portable, skills-only agent optimization plugin.

## Highlights

- ingests videos, articles, documentation, repositories, transcripts, files, and ideas;
- audits claims against current official and primary evidence;
- treats external material as untrusted input;
- separates analysis, deliberation, and explicitly authorized implementation;
- creates scoped proposals with validation, backup, and rollback;
- evaluates models and reasoning effort independently by task category;
- provides Codex and Claude Code plugin manifests from one canonical Skill;
- includes a 24-case behavioral evaluation suite and deterministic packaging.

- `agent-ingest-audit-optimize-0.1.0-plugin.zip` — complete Codex/Claude plugin.
