# Agent Ingest, Audit & Optimize v0.6.1

Two defects in what the archives ship, both found by a review of the plugin in November 2026, and
the repository tooling that review asked for. Neither defect is a new feature and neither changes
a command's interface.

## Changes

`docs/specs/2026-11-19-withheld-text-and-complete-archive.md`.

- **`scan` no longer copies any text out of a parsed file.** Redaction matched key names only, so
  a credential under a key no pattern named was copied into the baseline as written, and through
  `update` into the ledger file. Two shapes were reproduced with synthetic data against the
  shipped patterns: a hook command carrying a password argument, and a permission rule carrying an
  authorization header. Every string a parsed document holds is now replaced by a digest, whatever
  key it sits under. A baseline keeps the document's shape, its numbers, booleans and nulls, and
  one digest per string;
- three limits are stated rather than closed: a secret used as a key name is copied, a numeric
  secret is copied, and the digests are unsalted, so a short or common value can be confirmed by
  hashing a guess;
- **a baseline captured by 0.6.0 or earlier keeps the text it copied.** Capture a new one, and
  review old baselines before sharing a ledger;
- **the plugin archive now ships `commands/`.** The 0.6.0 plugin zip installed a plugin without
  its `/dashboard` command, because the packager's list never gained the directory. Two tests now
  check the archive against the repository instead of against the packager;
- known and not fixed: `/dashboard` invokes the bundle by a repository-relative path and is
  expected to fail when run from another project.

`docs/specs/2026-11-19-suites-off-the-clock.md` and `docs/specs/2026-11-19-minimal-ci.md`.
Repository tooling; nothing shipped changes.

- the three suites no longer fail on the calendar, and `check_evidence_freshness.py` is the one
  check that does read it;
- the suites run on every pull request and push to `main`, on Ubuntu and Windows.

The bundled adapters are still past their `expires_on` (2026-10-28) in this release, and `scan`
says so. No date was renewed: two of the three adapters need edits before a renewal is honest.
