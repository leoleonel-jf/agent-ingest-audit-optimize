# Agent Ingest, Audit & Optimize v0.8.0

A release that removes. The review of November 2026 found the plugin had grown faster than it was
used, and that one command stated things about a regulation and a standard that are wrong.

## Changes

`docs/specs/2026-11-19-the-cut.md`.

- **`compliance` is withdrawn.** It misidentified what it mapped: Article 13 of the EU AI Act was
  labelled human oversight (that is Article 14), three ISO/IEC 42001 controls were named wrongly
  and one does not exist, and the application date it gave has since moved. The command remains
  only to say it was withdrawn, and exits `2`. **A report or evidence pack it produced in 0.5.0 to
  0.7.0 carries these errors and should not be relied on.** The full correction is in the
  changelog;
- **The Skill no longer runs four tools on its own.** Sealing the hash chain, pinning a lockfile,
  building the dashboard and scanning a client's configuration all still work, and now run when
  you ask for them;
- **The roadmap is closed in writing.** What was planned and not built is named as abandoned.

Nothing you hold is touched: no ledger record is altered, and evidence packs you wrote stay where
they are.
