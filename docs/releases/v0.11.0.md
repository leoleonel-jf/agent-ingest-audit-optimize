# Plugin Reviewer v0.11.0

The plugin is now `plugin-reviewer`. Its marketplace and its repository were renamed with it.
The Skill, the commands, and the ledger are the same as in 0.10.0.

## If you installed it as `agent-ingest-audit-optimize`

The client does not finish the move for you. Each path below was tried through the `claude plugin`
and `codex plugin` commands, with an installation of 0.10.0 from a git marketplace added by URL,
on Claude Code 2.1.326 and codex-cli 0.146.0. The `/plugin` commands typed in a session and a
marketplace added as `owner/repo` were not tried.

Claude Code, with the marketplace under its new name:

```text
/plugin marketplace remove agent-ingest-audit-optimize
/plugin marketplace add leoleonel-jf/plugin-reviewer
/plugin install plugin-reviewer@plugin-reviewer
```

Claude Code, keeping the marketplace you already registered. After the update the plugin is no
longer listed as installed; the `renames` map has already rewritten its key in your settings, and
one install brings it back at 0.11.0:

```text
/plugin marketplace update agent-ingest-audit-optimize
/plugin install plugin-reviewer@agent-ingest-audit-optimize
```

The marketplace then keeps the name it was registered under.

Codex has no rename mechanism, and `codex plugin marketplace upgrade` refuses a marketplace whose
name changed (tried on codex-cli 0.146.0), so an existing installation stays at 0.10.0. Remove
both, then install as shown at the end of this page:

```text
codex plugin remove agent-ingest-audit-optimize@agent-ingest-audit-optimize
codex plugin marketplace remove agent-ingest-audit-optimize
```

What you type changes with the name: `/plugin-reviewer:dashboard` in Claude Code and
`$plugin-reviewer` in Codex.

Your ledger does not move. A machine that already has `<user-config>/agent-ingest-audit-optimize/`
(for Claude Code, `~/.claude/agent-ingest-audit-optimize/`) keeps using it where it is, and none of
the commands above touches it. Renaming that directory to `plugin-reviewer` is optional, and safe
when no recorded run keeps a backup inside it; `references/LEDGER.md` says what to check first.

## Changes

`docs/specs/2026-11-19-rename-plugin-reviewer.md`.

- **The name**: three manifests, both marketplaces, the Skill's directory, the `dashboard` skill's
  path, the evaluation suite, and the archives below. The display name is Plugin Reviewer;
- **A `renames` map** in the marketplace file, from the former name to this one;
- **The repository** is `leoleonel-jf/plugin-reviewer`. GitHub redirects the former address;
- **A new installation keeps its data in `<user-config>/plugin-reviewer/`.** An existing directory
  under the former name is used where it is, and is never moved, copied, or duplicated;
- **User adapters are read from both directory names** under `--user-config`, with a note for the
  former one. One client declared under both is refused, and the former name left as a link to the
  renamed directory is read once.

No ledger field, identifier, label, or command changed. A ledger written by 0.10.0 verifies under
0.11.0 and the reverse.

Validated on the extracted archive, outside any checkout, with Claude Code 2.1.326 and codex-cli
0.146.0. The upgrade of an existing installation and the move of a data directory are recorded in
`docs/validation/rename-0.11.0.md`.
