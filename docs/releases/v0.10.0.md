# Agent Ingest, Audit & Optimize v0.10.0

The Skill now leads with reviewing a plugin, a skill, or an MCP server before you adopt it.
Auditing a video, an article, or a repository about agent setup continues, behind it. No command
and no ledger rule changes.

## Changes

`docs/specs/2026-11-19-lean-skill.md`.

- **Review before adopting is the main path.** Six steps in `SKILL.md` and a checklist in
  `references/REVIEW.md` for a plugin, a skill, and an MCP server. Nothing under review is
  installed, enabled, or run in order to review it;
- **The description opens with that request**, the one the previous description missed, and fits
  the 1,024 characters the Agent Skills specification allows;
- **The verdict comes first**, in your language: adopt, adopt with changes, try in isolation
  first, not yet, or do not adopt. The two mandatory technical summaries are gone;
- **One record per review.** No baseline, no proposal record and no seal unless you ask for one or
  authorize a change;
- **Naming a change authorizes it, in any wording.** A bare "OK" still does not;
- **`references/LEDGER.md` is split into five files by subject**, with an index and a complete
  example of one review's record;
- Five verdicts replace thirteen classifications in the Skill. Every earlier label is still valid
  in a ledger, and a record written by this version verifies under earlier ones.

Validated on the extracted archive, outside any checkout, with Claude Code 2.1.326 and codex-cli
0.146.0. Activation and a review of a real plugin are recorded in
`docs/validation/lean-skill-0.10.0.md`.
