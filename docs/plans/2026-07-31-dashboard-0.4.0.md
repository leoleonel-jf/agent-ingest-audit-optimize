> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `dashboard.py build` and the self-contained `dashboard.html` shell: nine panels, the clipboard action model, `en`/`pt-BR` dictionaries, and the stored-XSS design from the spec — then release 0.4.0.

**Architecture:** One new module joins `ledgerlib/`: `build.py` (payload assembly reusing `drift_report`/`rollback_preview`/`validate_ledger`, the escaping serializer, template injection, atomic write). One large new asset: `assets/templates/dashboard.html`, vanilla JS, rendered exclusively through `createElement`/`textContent`. Python tests enforce the security properties statically; browser behavior is verified in the dogfood task.

**Tech Stack:** Python 3.10+ standard library only; `unittest`. The shell: HTML/CSS/vanilla JS, zero dependencies, zero requests.

**Spec:** `docs/specs/2026-07-31-dashboard-build.md`
**Design spec sections implemented:** §12 in full, §13 items 1–2, §14, §16 (0.4.0 acceptance), §17 (three eval additions).

## Global Constraints

- No third-party dependency anywhere. No CDN, no remote font, no network request of any kind from the generated file.
- Escaping contract (spec §1.1): after serialization there is **no literal `<` anywhere in the payload text**. The test is `self.assertNotIn("<", serialized)` — global, not pattern-based.
- Prohibited in the shell (spec §1.2): `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, `eval(`, `new Function`, `srcdoc`, `setTimeout("`, `setInterval("`, `javascript:`, and any `http://`/`https://` literal. The static test greps unconditionally — comments included, so don't even name them in comments.
- CSP meta tag, verbatim (spec §1.3): `default-src 'none'; img-src data:; style-src 'unsafe-inline'; script-src 'unsafe-inline'`.
- Canonical vocabulary (states, classifications, statuses, IDs, clipboard templates) renders in English in every UI language.
- Every finding message interpolating ledger content uses `!r`.
- **Every task ends in an ablation step.** Delete the code, run the suite, name the test that fails, restore, report verbatim.
- `.claude-plugin/plugin.json` → `version` is the single source of truth. Target `0.4.0`. Tags lightweight.
- This repository's own ledger (`.agent-audit/ledger.json`) is untracked and never staged. `.agent-audit/dashboard.html` must also never be staged (add to `.agent-audit/.gitignore` in Task 8's docs pass if not present).
- Run tests with: `python -m unittest discover -s dashboard/tests -v` (plus `packaging/tests`, `evals/tests` before release).

### Task 1: `serialize_payload` and `build_payload`

**Files:** Create `skills/agent-ingest-audit-optimize/assets/scripts/ledgerlib/build.py`; Create `dashboard/tests/test_build.py`.

**Interfaces:**
- Consumes: `validate_ledger(data, *, source) -> list[str]` (validate.py); `drift_report(ledger, *, adapter, user_config, project, bundled, environ, today) -> (report, messages, code)` (drift.py); `rollback_preview(ledger, run_id, *, ...) -> (report, messages, code)` (rollback.py); `load_json(path)` (paths.py); `LedgerError` (errors.py); `TOOL_VERSION` (constants.py — add if absent, sourced from one place).
- Produces: `serialize_payload(payload: dict) -> str`; `build_payload(ledger: dict, *, ledger_source: str, lang: str | None, adapter=None, user_config=None, project=None, today: str | None = None) -> tuple[dict, list[str]]` (payload, messages).

- [ ] **Step 1: Write the failing tests** — the serializer first, because it is the security core:

- serializing `{"title": "</script><script>alert(1)</script>"}` yields text containing no `<` at all; `json.loads` of it (after JSON unescape) round-trips the original string exactly;
- U+2028/U+2029 in a value serialize to their `\u` escapes; no raw U+2028/U+2029 in the output;
- output is deterministic: `sort_keys`, compact separators — two calls, one string;
- `build_payload` on a valid ledger fixture (reuse the fixture builders in `test_drift.py`) returns `payload_schema` 1, `mode` `"built"`, the ledger verbatim under `"ledger"`, and `computed.drift` equal to `drift_report`'s report for the same arguments — same code, not similar code: monkeypatch `drift_report` to a sentinel and assert the sentinel lands;
- `computed.previews` holds one entry per RUN record that names a backup, keyed by run ID; a run whose preview raises `LedgerError` lands as `{"error": "<message>"}` and build continues;
- a drift failure (`LedgerError`) lands as `computed.drift = {"error": ...}`, and the payload still builds;
- `computed.expired_evidence` lists each evidence entry across records with `expires_on` < `today`, carrying record ID, source, and `expires_on`; `today` is a parameter, both sides supplied by the test;
- `computed.unreachable_projects` lists `known_projects` entries whose recorded path does not exist now;
- a schema-invalid ledger raises `LedgerError` naming the first finding; nothing is computed;
- `lang` lands verbatim when given; falls back to `ledger["language"]`; an unknown code falls back to `"en"` and a message says so;
- `generated_at` is an ISO-8601 UTC timestamp; with `today` supplied, the date part equals `today` (determinism for tests).

- [ ] **Step 2: Run to verify failure** — `python -m unittest dashboard.tests.test_build -v` fails on import (`build.py` absent).

- [ ] **Step 3: Implement `build.py`** — serializer exactly as spec §1.1:

```python
def serialize_payload(payload: dict) -> str:
    text = json.dumps(payload, ensure_ascii=False, separators=(",", ":"), sort_keys=True)
    return (text.replace("<", "\\u003c")
                .replace("\u2028", "\\u2028")
                .replace("\u2029", "\\u2029"))
```

`build_payload` validates first (`validate_ledger`; findings → `LedgerError`), then computes drift, previews (every RUN with a non-null `backup`), expiry, reachability — each in its own try/except `LedgerError` → `{"error": str(e)}`. No file I/O in this function beyond what `drift_report`/`rollback_preview` already do; it takes the ledger dict, not a path.

- [ ] **Step 4: Run tests to verify pass.**
- [ ] **Step 5: Ablation** — delete the two `.replace` escape lines; name the failing test; restore. Delete the `validate_ledger` call; name the failing test; restore.
- [ ] **Step 6: Commit** — `feat: payload assembly and escaping serializer for build`.
